# Frameling

**An open-source animated video maker.** Pick a scene, drop in characters and props, choose
an action and an expression, give them a voice with automatic lip sync, string scenes
together, and export an MP4. Runs as a desktop app on Windows, macOS and Linux, and in
the browser.

> Working name. Everything here (code, characters, props, backgrounds) is original and
> released under permissive licences. No assets or branding from other products.

## What's in v0.1

- **Scene editor**: drag, scale, rotate, flip and layer characters, props and text on a 1280×720 stage (also 1080p, vertical 9:16 and square).
- **Character creator**: remix parts (body, hair, eyes, brows, nose, facial hair, clothes and 22 wearables such as hats, headphones, glasses, earrings, capes and held props) with a live animated preview, colours, randomise with locks, undo and a My characters library. Import your own part packs; AI agents can design characters from a description. See [docs/CHARACTERS.md](docs/CHARACTERS.md).
- **Turnaround**: 8 views (front, 3/4, side, 3/4 back, back) for every character, keyable, with walking that turns to face where it goes and the far arm and leg behind the body.
- **Walking and poses**: a 2D walk cycle (contact, down, passing, up) with planted feet and arm swing, a run with a flight phase, and a library of 38 reusable poses (sit, kneel, lie, point, phone call...) you can hold with blends, apply to the upper body only, key, or chain into new animations. See [docs/POSES.md](docs/POSES.md).
- **Characters**: 6 ready-made characters and 8 stick figures to start from, 13 actions (idle, talk, wave, walk, run, jump, cheer, think, point, shrug, clap, dance, sad) and 7 expressions, with automatic blinking.
- **Voices and lip sync**: select a character, type a line and pick a voice (**built-in offline text-to-speech**), record with the mic, or upload a file. Lines play one after another, the scene grows to fit, and the character lip-syncs and gestures. See [docs/VOICES.md](docs/VOICES.md).
- **Agent-native**: an MCP server (`frameling mcp`) lets AI agents read the scene, use the library and voices, apply any edit, make characters talk, look at rendered frames and export. They can also turn a screenplay into a video. The desktop app updates live while an agent works. See [docs/AGENTS.md](docs/AGENTS.md).
- **Movement**: give anything a start and end point; characters walk there and face the way they're going.
- **Auto-key animation**: set an item up, move the playhead ahead and change it (drag, resize, rotate, expression, skin, hair or clothing colours, hair style, accessories, opacity, flip). The change becomes a keyframe at the playhead, with the first setting keyed at the item's start, so it animates between them. Keyframes show as diamonds on the timeline; the Auto-key switch in the inspector turns it off.
- **Text**: speech and thought bubbles, captions and titles, with a typewriter effect.
- **Scenes and timeline**: scene strip with drag-to-reorder and transitions (crossfade, dip to black, slide, zoom); per-scene tracks with draggable timing bars; camera pan and zoom.
- **Effects**: fade, pop and slide in/out per item.
- **Export**: frame-exact MP4 (H.264 + AAC) or WebM. Desktop uses FFmpeg; the browser uses WebCodecs.
- **Files**: one portable `.frameling` file (JSON with embedded audio), autosave, unlimited-ish undo (200 steps).
- **Asset packs**: add props, backgrounds and new character actions with a JSON file. No code needed.

## Quick start

Prerequisites: [Rust](https://rustup.rs) (stable), Node.js 20+, and FFmpeg on your PATH for desktop export.

```bash
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.130

cd app
npm install
npm run dev            # web version at http://localhost:5173
npm run fetch-tts      # once: download the built-in voices (Supertonic 3, ~400 MB, OpenRAIL-M)
npm run tauri dev      # desktop app (needs the Tauri prerequisites for your OS)
npm run tauri build    # installers for your OS, voices included
```

Tauri system prerequisites (WebView2 on Windows, Xcode CLT on macOS, webkit2gtk on Linux):
<https://v2.tauri.app/start/prerequisites/>

### Command line

```bash
cargo run --release -p frameling-cli -- demo demo.frameling
cargo run --release -p frameling-cli -- render demo.frameling demo.mp4 --width 1920
cargo run --release -p frameling-cli -- still demo.frameling 45 frame.png
cargo run --release -p frameling-cli -- apply demo.frameling commands.json out.frameling
```

`apply` runs a JSON list of editor commands, so videos can be generated by scripts.

```bash
frameling voices                                             # list voices
frameling say movie.frameling scene-1 maya "Hello there!"   # add a spoken, lip-synced line
frameling script story.txt movie.frameling                   # screenplay -> project
frameling mcp movie.frameling                                # MCP server for AI agents
```

Use a release build's binary or `cargo run --release -p frameling-cli --` in place of `frameling`.

## How it works

```
crates/core     document model, commands + undo, asset packs, character rig, timeline evaluate()
crates/render   display list -> pixels (tiny-skia); same code in WASM preview and native export
crates/export   frame-by-frame export, frames piped to FFmpeg, audio placed by frame number
crates/wasm     the engine as a WebAssembly module for the editor UI
crates/tts      offline text-to-speech (bundled Supertonic 3 on ONNX Runtime, OS voices fallback)
crates/cli      headless rendering, automation, screenplays and the MCP server
app/            Svelte + TypeScript editor UI (shared by desktop and web)
app/src-tauri   Tauri 2 desktop shell: native files and native export
packs/core      the built-in asset pack (generated by tools/build_core_pack.py)
```

The key idea: `evaluate(project, frame) -> DisplayList` is a **pure function of an integer frame
number**. The editor preview, the browser exporter and the native exporter all call it and
draw with the same renderer, so what you see is exactly what you export, and export never
drops frames on a slow machine. See [ARCHITECTURE.md](ARCHITECTURE.md).

## Customising

- **Asset packs**: Props tab → *Load asset pack…*. Format in [packs/README.md](packs/README.md), example in [packs/examples/space-pack.json](packs/examples/space-pack.json).
- **Theme**: every colour of the editor is a CSS variable in `app/src/styles.css`.
- **Automation**: everything the UI does is a JSON command (`crates/core/src/command.rs`), usable from the CLI.
