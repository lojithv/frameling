# Fonts

Text is turned into vector outlines inside the engine, so these files are
compiled into the app (`crates/core/src/text.rs`). Each is used unmodified
under its own licence. The app shows them under generic names.

| File | App name | Family | Licence |
|---|---|---|---|
| `Inter-SemiBold-subset.otf` | Sans | Inter SemiBold (Latin subset) | SIL OFL 1.1 (`OFL.txt`) |
| `Figtree-Black.ttf` | Heavy | Figtree Black, Copyright 2022 The Figtree Project Authors | SIL OFL 1.1 |
| `Poppins-Bold.ttf` | Rounded | Poppins Bold, Copyright 2020 The Poppins Project Authors | SIL OFL 1.1 |
| `RobotoMono-Bold.ttf` | Mono | Roboto Mono Bold, Copyright 2015 Google Inc. | Apache License 2.0 |
| `KaTeX_Main-Bold.ttf` | Serif | KaTeX Main Bold, Copyright 2009-2010 Design Science, Inc., 2014-2018 Khan Academy (Reserved Font Name "KaTeX_Main") | SIL OFL 1.1 |

The SIL Open Font License text is in `OFL.txt` (it is the same licence for
every OFL font above; only the copyright line differs). The Apache License 2.0
text is at <https://www.apache.org/licenses/LICENSE-2.0> and in the
repository's `LICENSE-APACHE`.
