# Walking, running and the pose library

## Walk and run cycles

Characters with **Walk while moving** on walk whenever their position changes (position
keys or the old one-segment movement). The cycle is built from the classic 2D breakdown:
**contact, down, passing, up** for each step, with leg IK, a hip bounce, arms swinging
against the legs and a slight lean into the walk.

- **Planted feet.** The cycle follows the distance travelled, not the clock, so the standing
  foot stays put while the body moves over it.
- **Speed.** Faster moves take longer steps (up to 1.6×). Above a brisk walk the cadence caps,
  and moves faster than about 270 px a second at full size become a **run**, with a flight
  phase where both feet leave the ground.
- **On the spot.** The Walk and Run actions play the same cycles in place.

### Where and when a move starts

With Auto-key on, move the playhead ahead and drag the character: it walks from where it was
at its first frame to the new spot. To choose the start yourself:

- **Stage**: the selected character's path shows a green **Start** point and a yellow **End**
  point (and any points between). Drag a point to move it; click it to jump there.
- **Timeline**: drag the character's keyframe diamonds to change when each point happens,
  e.g. drag the first diamond to 3 s so the character stands still until 3 s, then walks.
  A click without dragging jumps the playhead.
- **Inspector → Movement**: a row per point with its time, X and Y. Type exact values, use ⤓ to
  move a point to the playhead's time, ✕ to remove a point, or add a point at the playhead.

Before the start and after the end the character stands still.

## Poses

A pose is a set of joint values on the shared skeleton, so every pose fits every character:
cartoon, stick figure, or one made in the character creator. The library has 38 poses:

| Group | Poses |
|---|---|
| Standing | stand, relaxed, hands on hips, arms crossed, fists clenched, shrug, thinking, facepalm, scared, tiptoe, arms out, hands up |
| Gestures | point, wave, talk (one or both hands), thumbs up, phone call, cheer, clap, salute, presenting |
| Sitting and kneeling | sit on a chair, sit with arms crossed, sit on the phone, sit on the floor, kneel, kneel with arms crossed, kneel and cheer, crouch |
| Lying | on the back, on the side, on the front |
| Motion keys | walk stride, walk passing, run stride (from the walk cycle), jump crouch, jump peak |

Sitting, kneeling and lying poses rest on the floor automatically (the `ground` joint), whatever
the body shape.

### Using a pose (inspector → Poses)

- **Hold**: the pose from the playhead for a length, blending in and out of whatever the
  character was doing. It shows on the character's timeline row as a purple strip. Held poses
  breathe a little so they don't freeze.
- **Body part**: Whole body, Upper body (plays over walking and talking), Legs, Left arm or Right arm.
- **Mirror**: the same pose facing the other way.
- **Key**: writes the pose as bone keyframes at the playhead. Key several poses at different
  times to animate pose to pose. Keys replace the action on those joints for the whole scene.
- **Make animation**: click poses in order, set how long each holds and how long each move
  takes, and it becomes an animation any character can play from **Action** (marked ★).
- **Save this character's current pose** keeps whatever the character is doing at the
  playhead as a new pose in the project.

### Joints

| Joint | Track path | Meaning |
|---|---|---|
| `ls`, `le`, `rs`, `re` | `bone.upper_arm_l.rot`, ... | shoulders and elbows, degrees |
| `lh`, `lk`, `rh`, `rk` | `bone.thigh_l.rot`, ... | hips and knees, degrees |
| `lean`, `head`, `bob`, `rise`, `look`, `thumb` | `bone.spine.rot`, ... | as before |
| `drop` | `bone.hips.drop` | lower the hips; the legs bend |
| `fold` | `bone.thigh.fold` | shorten the thighs 0–0.9 (sitting, seen from the front) |
| `kneel` | `bone.shin.fold` | shorten the shins 0–0.9 (kneeling) |
| `tilt` | `bone.root.tilt` | rotate the whole body around the hips (lying) |
| `ground` | `bone.root.ground` | 0–1: rest the lowest point of the body on the floor |

### Pose packs

Packs can add poses with a `poses` list (see [packs/README.md](../packs/README.md)):

```json
{ "id": "my-poses", "name": "My poses", "poses": [
  { "id": "victory", "name": "Victory", "category": "Gestures", "tags": ["win", "yes"],
    "pose": { "ls": 150, "le": 20, "rs": 40, "re": 120, "head": -4 } }
] }
```

The built-in set is generated by `tools/build_pose_pack.py`, which also has the arm and leg IK
helpers for placing hands and feet.

### Agents (MCP)

`list_poses`, `add_pose_strip` (hold, blends, mask, mirror), `remove_pose_strips`,
`apply_pose` (keys), `save_pose` (from values, or from a character at a time) and
`make_clip_from_poses`. See [AGENTS.md](AGENTS.md).
